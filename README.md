# 俄罗斯方块微信小程序

标准微信小程序版俄罗斯方块：Canvas 渲染、手势 / 按钮控制、落点提示、本地最高分。

## 运行
1. 微信开发者工具导入 `tetris-miniprogram` 目录
2. 替换 `project.config.json` 中的 AppID（当前为游客模式 `touristappid`，可预览）
3. 预览 / 上传 / 发布

## 功能
- 7 种方块（I/O/T/S/Z/J/L）、旋转踢墙、幽灵落点、Next 预览
- 消行计分（单/双/三/四行 100/300/500/800 × 等级）、每 10 行升级加速
- 最高分本地存储、暂停 / 继续 / 重开
- 操作：屏幕按钮 + 滑动手势（←→ 移动、↓ 硬降、轻点旋转）

## 目录
- `app.js` / `app.json` / `app.wxss` 全局配置
- `utils/tetris.js` 核心引擎（纯逻辑）
- `pages/game/` 游戏页（Canvas 渲染 + 交互）
